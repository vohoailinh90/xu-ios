# Xu — ghi chi tiêu trong 2 giây (iOS)

Xu là cách nhanh nhất để ghi chi tiêu trên iPhone: gõ một câu, xong trong 2 giây, không cần ngân hàng, không cảm giác tội lỗi.

```
"cà phê 35k"        →  35.000đ · ☕ Cà phê & đồ uống · Hôm nay
"grab 52k hôm qua"  →  52.000đ · 🛵 Di chuyển · Hôm qua
"lương +15tr"       →  +15.000.000đ · 💰 Lương · Hôm nay
```

## Trạng thái
